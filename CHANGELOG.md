# Changelog

All notable changes to Zashboard Rule Intelligence are documented here. Project versions are
independent from the incorporated Zephyruso/zashboard upstream version.

## v1.0.0

- Initial public source release of Zashboard Rule Intelligence.
- Based on Zephyruso/zashboard v3.24.0 at commit `f6dd9c07`.
- Includes Rule Search, Rule Penetration, proxy-chain resolution, fallback detection, Rule Provider
  Explorer, Text/YAML/MRS Provider support, bare-Mihomo custom rules, and the minimal Local Helper.
- Includes public install, upgrade, uninstall, CI, and isolated installer-test workflows.

For the inherited upstream project's earlier changes, see the
[Zephyruso/zashboard changelog](https://github.com/Zephyruso/zashboard/blob/main/CHANGELOG.md).
